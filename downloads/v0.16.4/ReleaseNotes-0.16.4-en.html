DeskNest 0.16.4

Channel: stable; build: 0.16.4.65535; Windows x64.

  • Adds unified Box backgrounds across title, tabs and content, with matching per-Box and default settings while preserving existing appearances.
  • Unifies title-bar and three-dot menus, separates Box and desktop commands, and groups common and advanced appearance options.
  • Fixes ignored Box spacing under Windows desktop metrics and a crash when a Box is destroyed while its menu is open.
  • Improves large Folder Portal scans and corrects Mica opacity, rounded corners and Station position drift.
  • Preserves existing settings, preview cancellation and file-safety boundaries. Station remains disabled by default.
