# DeskNest 0.16.1

- Channel: stable
- Build version: 0.16.1.65535
- Windows x64 stable release.
- Fixes duplicate automatic-classification boxes and incorrect directory grouping.
- Keeps per-Box background images visible across refreshes and layout updates.
- Upgrades Box materials and adds configurable corner radius.
- Restores Folder Portal thumbnails and grid/list view switching.
- Keeps Box header controls aligned and limits drag cursors to draggable areas.
- Adds DeskNest-styled Chinese and English color and input dialogs.
- Installed and portable packages use separate signed update feeds.
- Stable releases migrate existing beta clients to the stable channel.
