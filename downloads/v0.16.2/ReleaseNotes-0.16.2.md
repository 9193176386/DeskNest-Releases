# DeskNest 0.16.2

## 简体中文

- 更新通道：stable
- 构建版本：0.16.2.65535
- 补齐设置中心及相关对话框的英文翻译，并新增漏译回归检查。
- 修复设置中心在最小窗口宽度下英文内容被裁切的问题。
- 更新说明、更新弹窗和便携版更新器会跟随所选界面语言显示中文或英文。
- 改进 Folder Portal 的返回、前进和上级按钮反馈。
- 保持现有安全更新、桌面文件和 Box 外观行为不变。

## English

- Channel: stable
- Build version: 0.16.2.65535
- Windows x64 stable release.
- Completes English translations for Settings and related dialogs with regression checks.
- Fixes clipped English content when Settings is at its minimum window width.
- Localizes update notes, update dialogs, and the portable updater to the selected language.
- Improves feedback for Folder Portal back, forward, and up controls.
- Keeps existing safe update, desktop-file, and Box-appearance behavior unchanged.
