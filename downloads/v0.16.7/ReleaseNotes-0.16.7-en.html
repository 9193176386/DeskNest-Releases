DeskNest 0.16.7

Channel: stable; build: 0.16.7.65535; Windows x64.

  • Fixes window lifetime issues that could crash DeskNest during Windows 11 shutdown or restart.
  • Redesigns Settings with a flat interface, smooth sidebar resizing, fixed menu icon positions and reduced startup flicker.
  • Fixes intermittent slow wheel scrolling and repeated style refreshes triggered by screen capture; adds scrollbar fading.
  • Improves Windows 11 native context and tray menus and keeps Box text white.
  • Removes unused machine-learning runtimes and Qt translations; upgrades clean up these obsolete files while preserving user data.
