DeskNest 0.18.1

Channel: stable; build: 0.18.1.65535; Windows x64.

  • Adds layout and configuration state-package restore with preview, folder remapping, restart, pre-restore snapshots and failure rollback.
  • Shares Settings, auto-organization and supporting dialog workflows across Windows 10 and Windows 11, with platform-specific styles and materials.
  • Fixes shutdown hanging while organization history loads, and improves initial opening, cancellation and closing of Windows 11 native menus.
  • Fixes Windows 11 Acrylic materials failing to refresh after custom color or tint opacity changes.
  • Removes unused QML debugging and TUIO plugins from release packages while retaining required graphics, material and network runtimes and preserving user data on upgrade.
