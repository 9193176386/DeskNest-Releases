# DeskNest 0.15.3

- Channel: stable
- Build version: 0.15.3.65535
- Windows x64 stable release.
- Improves Windows 10 and Windows 11 Explorer desktop-host compatibility.
- Box appearance controls now preview changes immediately.
- Cancelling appearance or color changes restores the previous Box style.
- Installed and portable packages use separate signed update feeds.
- Stable releases migrate existing beta clients to the stable channel.
