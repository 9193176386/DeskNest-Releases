# DeskNest 0.16.0

- Channel: stable
- Build version: 0.16.0.65535
- Windows x64 stable release.
- Reorganizes Settings into a clearer, searchable information architecture.
- Adds five Box materials and Windows 11 Mica with safe fallback behavior.
- Adds editable organization rules and improves automatic organization.
- Refreshes desktop search and layout-history interfaces.
- Keeps Settings open while secondary actions and dialogs are used.
- Includes stability fixes across persistence, desktop integration, and UI state handling.
- Installed and portable packages use separate signed update feeds.
- Stable releases migrate existing beta clients to the stable channel.
