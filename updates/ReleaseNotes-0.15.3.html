DeskNest 0.15.3

Channel: stable; build: 0.15.3.65535; Windows x64.

  • Improved Windows 10 and Windows 11 Explorer desktop-host compatibility.
  • Box appearance controls now preview changes immediately.
  • Cancelling appearance or color changes restores the previous Box style.
  • Installed and portable updates are separated and Ed25519-signed.
  • Stable releases migrate existing beta clients to the stable channel.
