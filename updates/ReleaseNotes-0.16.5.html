DeskNest 0.16.5

简体中文

更新通道：stable；构建版本：0.16.5.65535；Windows x64。

  • 修复主动移除自动分类 Box 后，后台桌面刷新又创建该 Box 的问题。
  • 记住移除自动分类 Box 的选择，重启程序后仍然有效。
  • 保留手动整理创建分类 Box 的能力；普通 Box 的移除不影响自动分类。
  • 升级后如旧的分类 Box 已重新出现，请再次移除一次，新版本会记住该选择。
  • 保留旧配置、实时预览取消回滚及文件安全边界；中转站仍默认关闭。

English

Channel: stable; build: 0.16.5.65535; Windows x64.

  • Fixes automatic classification Boxes being recreated by background desktop refreshes after manual removal.
  • Remembers dismissal of automatic classification Boxes across application restarts.
  • Keeps explicit organization available; removing ordinary Boxes does not disable automatic classification.
  • If an old classification Box has already reappeared, remove it once after upgrading so this version can remember your choice.
  • Preserves existing settings, preview cancellation and file-safety boundaries. Station remains disabled by default.
