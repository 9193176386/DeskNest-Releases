DeskNest 0.17.1

简体中文

更新通道：stable；构建版本：0.17.1.65535；Windows x64。

  • Windows 11 默认启用新版设置中心与一体式标题栏；外观、搜索、整理及提示窗口保持一致的操作体验。
  • 修复 Windows 11 云母背景和提示框黑底，窗口随应用浅色、深色或系统主题切换。
  • 简化 Windows 11 自动整理：优先展示推荐方案，需要时再展开自定义选项，保留安全校验与确认。
  • 修复收起侧栏后的图标裁切和桌面拖选残影，并保留最新粘贴目标与撤销改进。
  • Windows 10 保留原有窗口风格；安装版与便携版继续包含完整材质运行库，升级保留用户数据。

English

Channel: stable; build: 0.17.1.65535; Windows x64.

  • Enables the redesigned Settings and integrated title bars by default on Windows 11, with consistent appearance, search, organization and message dialogs.
  • Fixes Windows 11 Mica rendering and black message-box backgrounds; dialogs follow the selected light, dark or system theme.
  • Simplifies Windows 11 auto-organization with a recommended plan first and optional customization, while retaining validation and confirmation safeguards.
  • Fixes clipped collapsed-sidebar icons and desktop selection trails, and includes the latest paste-target and undo improvements.
  • Retains the existing window style on Windows 10; installed and portable packages keep the full material runtime and preserve user data during upgrades.
