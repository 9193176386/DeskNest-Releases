DeskNest 0.16.3

Channel: stable; build: 0.16.3.65535; Windows x64.

  • Stages Settings changes as one batch and commits them atomically; failures restore startup, hotkey, and Station configuration.
  • Gives Station managed local storage plus copy-based staging for files, screenshots, and text, with drag-out and explicit cleanup.
  • Fixes Station edge reveal, auto-collapse, toolbar shortcuts, and keyboard menu placement while reducing hidden-state resource use.
  • Adds a skippable Chinese and English Quick Start for Boxes, Folder Portals, Station, search, and layout recovery.
  • Station remains an opt-in experimental feature. It never collects clipboard history or clears stored items automatically.
